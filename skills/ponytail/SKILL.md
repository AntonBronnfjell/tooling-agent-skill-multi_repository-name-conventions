# Ponytail

Apply Ponytail guidance to the current task.

- Start with the result the user needs, not a grand redesign.
- Reuse existing code, patterns, and tools before inventing new ones.
- Prefer native platform features and current dependencies over adding more.
- Make the smallest correct change that fully solves the problem.
- Keep code boring, readable, and easy to review.
- Validate with the narrowest useful test or check.

If the caller includes an intensity, scale how aggressively you trim scope
while still delivering a complete, correct solution.
